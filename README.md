# MultiBot Video Studio

Локальна студія для монтажу відео. Вона запускається на Mac і відкривається у браузері.

## Доступ і встановлення

Сховище приватне. Для встановлення з GitHub потрібен доступ до нього та вхід у GitHub на комп'ютері. Передайте Codex посилання на сховище і попросіть встановити студію на Mac. Codex допоможе налаштувати доступ, завантажити програму в окрему папку всередині папки YOUTUBE та перевірити потрібні інструменти. Папки каналів студія шукає поруч зі своєю папкою.

Для запуску потрібні Python 3 і Git. Для роботи з відео та експорту також потрібні FFmpeg і ffprobe. Окремим функціям, наприклад аналізу озвучки, можуть знадобитися додаткові компоненти. Codex допоможе їх перевірити й встановити за потреби.

Відкрийте папку студії та запустіть файл «Запустить студию.command». Студія відкриється у браузері. Під час роботи залишайте вікно запуску відкритим.

## Оновлення

Студія перевіряє наявність нової версії при запуску. Якщо оновлення доступне під час роботи, у студії передбачена кнопка оновлення. Для отримання оновлень потрібен доступ до приватного сховища та інтернет. Роботу кнопки на новому комп'ютері потрібно перевірити після встановлення.

Можна також попросити Codex оновити студію. Він перевірить локальні зміни та збереже їх перед оновленням. Дочекайтеся завершення експорту й обробки озвучки перед перезапуском.

Проєкти й медіа зберігаються локально. Код програми на GitHub не є резервною копією випусків, тому для перенесення проєктів на інший Mac їх потрібно перенести окремо.

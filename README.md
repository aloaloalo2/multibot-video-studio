# VideoKey Studio

Локальна студія для монтажу відео. Вона запускається на Mac і відкривається у браузері.

## Доступ і встановлення

Передайте Codex, Claude Code або іншому агенту посилання на це сховище і попросіть встановити студію на Mac. Сховище відкрите, тому для завантаження акаунт GitHub не потрібен. Агент допоможе завантажити програму в окрему папку всередині папки YOUTUBE та перевірити потрібні інструменти. Папки каналів студія шукає поруч зі своєю папкою.

Для запуску потрібні Python 3 і Git. Для роботи з відео та експорту також потрібні FFmpeg і ffprobe. Окремим функціям, наприклад аналізу озвучки, можуть знадобитися додаткові компоненти. Codex допоможе їх перевірити й встановити за потреби.

Відкрийте папку студії та запустіть файл «Запустить студию.command». Студія відкриється у браузері.

На Mac з Apple Silicon експорт роликів до 1080p і 30 кадрів за секунду використовує графічний процесор, якщо доступні інструменти Swift. Складні матеріали обробляються перевіреним способом; якщо швидкий режим недоступний, студія продовжує звичайний експорт і повідомляє про це.

Підготовка наступних кадрів відбувається під час експорту вже підготовлених. Студія зберігає готові частини в локальному кеші до 4 ГБ. Повторний експорт використовує незмінені частини; зміни матеріалів, тексту, шрифту, ефектів чи таймінгів автоматично враховуються. Зміни звуку дозволяють повторно використати готове зображення й зібрати нову звукову доріжку. Кеш можна видалити без втрати проєктів: він розташований у `~/Library/Caches/MultiBotVideoStudio/render-v2`. Вихідні медіа залишаються без змін.

Під час експорту картка випуску показує прогрес, а кнопка експорту має рухомий індикатор. Проєкт залишається заблокованим до завершення або скасування експорту. Закриття вікна експорту дозволяє повернутися до інших випусків.

У попередньому перегляді лупи дозволяють збільшити кадр від 100% до 400%. Збільшений кадр можна перетягувати. Натискання на відсоток повертає масштаб 100%.

## Оновлення

Студія перевіряє наявність нової версії при запуску. Якщо оновлення доступне під час роботи, у студії передбачена кнопка оновлення. Для отримання оновлень потрібен інтернет. Роботу кнопки на новому комп'ютері потрібно перевірити після встановлення.

Можна також попросити Codex оновити студію. Він перевірить локальні зміни та збереже їх перед оновленням. Дочекайтеся завершення експорту й обробки озвучки перед перезапуском.

Проєкти й медіа зберігаються локально. Код програми на GitHub не є резервною копією випусків, тому для перенесення проєктів на інший Mac їх потрібно перенести окремо.

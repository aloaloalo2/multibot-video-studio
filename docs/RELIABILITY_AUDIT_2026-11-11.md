# Повторна ревізія надійності 11 листопада 2026

Перевірено основні етапи створення випуску, від тем і зачинів до експорту, а також переклади, черги, перезапуск, відображення станів і витрати контексту. Цей прогін доповнює попередній CODE_AUDIT_2026-11-11.md. Попередні правки й матеріали користувача збережено.

## Виправлено

| Ділянка | Підтверджена проблема | Зміна |
| --- | --- | --- |
| Запуск фонових задач | Відмова запуску могла залишити зайнятий слот і незмінний стан роботи | Режисер, створення кадрів, теми, сценарії, прев’ю, переклади, агент, зразок голосу й звук звільняють бронювання та публікують помилку запуску |
| Початковий запис | Помилка запису озвучки могла залишити порожній перший елемент черги HeyGen, блокуючи наступні випуски | Невдале збереження прибирає запис із черги до запуску синтезу |
| Розпізнавання | Помилка створення робочої папки або останнього запису могла залишити активне розпізнавання без працівника | Завершення звільняє реєстрацію задачі навіть при помилці диска; неуспішне створення покажчика також відкочується |
| Працюючі автори | Помилка запису активності або обробки потоку могла залишити автора працювати після невдалого завершення задачі в студії | Дочірній процес примусово зупиняється й очікується його вихід; для режисера враховуються нащадки, які створили окремі групи процесів |
| Працюючі кодувальники | Помилка запису прогресу могла залишити кодувальник працювати після звільнення черги | Перед звільненням слота кодувальник зупиняється; наступний експорт отримує звільнений ресурс |
| Передача роботи | Між завершенням режисури й запуском кадрів могла виникати мить без зареєстрованої роботи | Передача використовує спільний короткий захист із перезапуском. Зареєстровані працівники залишаються зайнятими до завершення передачі й прибирання |
| Автоозвучка | Невдалий автоматичний запуск міг замінити стан уже запущеної вручну озвучки | Помилка автоматичної передачі не переписує активний ручний запуск |
| Автомонтаж | Завершення озвучки публікувалося до реєстрації наступного етапу | Озвучка утримує свій слот до передачі; у режимі «Без плану» запускається звичайне розпізнавання без запиту кадрів |
| Зачини | Запізнілий результат читання міг повернути старі зачини після вибору зачину та запуску сценарію | Читання й дії прив’язані до поточної версії панелі; старі відповіді відкидаються |
| Оновлення статусів | Тимчасова помилка читання могла повністю зупинити опитування зачинів або озвучки | Активні стани відновлюють читання з паузою. Повторюється лише GET. Нові генерації автоматично не запускаються |
| Перехід між випусками | Запізніла відповідь озвучки могла змінити індикатор іншого каналу чи випуску | Перевіряється належність до актуального проєкту після отримання відповіді; закриті панелі припиняють оновлення |
| Збереження MP4 | Переміщення готового файла між дисками завершувалося EXDEV після рендеру | Для іншого диска файл спочатку повністю копіюється в тимчасовий файл на диску призначення, потім публікується |
| Наявні експорти | Файл, створений іншою програмою після вибору назви, міг бути затертий | Публікація використовує захист від перезапису; перевірено також файлові системи без жорстких посилань |
| Скасування копіювання | Велике копіювання могло блокувати керування або лишити неповний результат | Копіювання перевіряє скасування між блоками, не утримує загальний замок експорту, прибирає тимчасовий файл |
| Допоміжні операції | Відмова запуску оновлення мовного звуку могла позначити вже готовий MP4 як невдалий | Готовий результат експорту зберігає успішний статус незалежно від запуску допоміжного оновлення |
| Кеші | Відмова фонового запуску могла назавжди залишити позначку підготовки гучності або каталогу голосів | Позначки очищуються; поточне аудіо й збережений каталог залишаються доступними |
| Облік витрат | Відмова запуску фонової статистики могла вплинути на результат автора | Первинний журнал залишається доступним для наступного локального підрахунку |
| Метадані | Окреме дописування метаданих знову надсилало повний сценарій | Запит обмежено початком і кінцівкою сценарію, разом до 1600 символів, назвою й вимогами до метаданих |

| Розпізнавання | Порядок фраз, відповідність тексту, числові форми, локальне відновлення спірних фраз, повторне використання доказів, передача режисеру, помилки диска |

| Переклади | Частини тексту в правильному порядку, продовження, готові оплачені фрази, перевірки мови й змісту, збереження аудіо, відмова фонового запуску |
| Експорт | Черга, скасування, перехід до наступного експорту після помилки, GPU і резервний режим, короткі реальні синтетичні MP4, межі кадрів, фінальна пауза, збереження між дисками |

## Результати перевірок

- Backend: 1020 тестів, 92,2 с.
- Frontend: 166 тестів.
- Відеорушій: 85 тестів, 49,7 с.
- Інструменти: 55 тестів.
- Разом: 1326 тестів, включно з 34 новими регресійними тестами цього прогону.
- Після завершальних правок повторно перевірено 41 тест зупинки процесів, передачі роботи, режисури й черги озвучки.
- Статична перевірка 32 frontend-файлів пройшла; змінені Python-модулі перевірено на невизначені імена й невикористані імпорти.
- `git diff --check` пройшов.

Перевірка відмов запускає локальні сплячі процеси й навмисно створює помилки запису. Записи Disk full, Pipe failed і Missing result у тестових журналах належать цим контрольованим випадкам.

На момент заміру у працюючій студії прочитано списки 32 проєктів у шести каналах. Перші відповіді займали 33–476 мс, повторні 11–103 мс; `/api/studio/status` відповів за близько 1 мс. Це заміри локальних API у студії без активних робіт; вони не вимірюють час генерації постачальників чи повне завантаження відео.

## Межі перевірки

Платні постачальники сценаріїв, голосу, перекладів і картинок замінені контрольованими відповідями. Справжні платні роботи на авторських проєктах не запускалися. Короткі синтетичні експорти перевіряють технічний шлях рендеру. Повний перегляд і прослуховування кожного авторського ролика цей прогін не виконує.

Перевірки охоплюють перелічені умови. Якість художнього рішення моделі та поведінку зовнішніх API під реальним навантаженням вони не гарантують.

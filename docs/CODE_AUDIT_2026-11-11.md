# Ревізія коду VideoKey Studio 11 листопада 2026

Виправлено підтверджені помилки в роботі запитів, переходів між проєктами, діалогів, медіатеки й передачі роботи режисеру. Прибрано підтверджений невикористаний код. Повний повторний прогін завершився без тестових збоїв. Зміни застосовано через штатний захищений перезапуск студії, коли активних робіт не було.

Цей звіт стосується поточної ревізії. У робочій папці також залишаються зміни з попередніх погоджених завдань; їх не відкидали й не замінювали.

## Прибраний код і виправлені перевірки

- Видалено дві функції без робочих викликів: `directorDone` і `thumbnailFramesMade`.
- Видалено кеш `thumbnailPictures`, у який дані записувалися без жодного читання.
- Прибрано зайвий префікс форматованого рядка в діагностичному інструменті випуску.
- Оновлено застарілі тестові умови: зачини по 6 речень, генерація тем при відкритті вкладки замість фонового розкладу, новий вбудований сценарний блок і залежності клонування прев'ю.
- Додано 15 регресійних тестів для знайдених проблем. Внутрішні сценарії цих тестів перевіряють кілька варіантів запізнілих відповідей, некоректних чисел і діапазонів медіа.
- Виправлено документацію видалення: постійне видалення керованого проєкту не описується як відновлюване. Уточнено актуальні перевірки озвучки й порядок передачі режисеру.

Збережено необхідні сумісні інтерфейси. Імпорт `mlx_whisper` перевіряє доступність прискореного розпізнавання. `narration_pacing.MAX_SPEED` використовується іншим модулем як публічний параметр. Діагностику цих двох імпортів перевірено вручну; їх видалення порушило б наявну поведінку.

## Межі цієї ревізії

Перевірено код основної студії та синтаксис встановлених і упакованих компонентів Razgon. Генеровані проєкти, сторонні `node_modules`, медіа й кеші не використовувалися як кандидати для автоматичного видалення.

Тести постачальників використовують заміни зовнішніх API. Реальні платні озвучки, нові сценарії, картинки, переклади та експорти авторських випусків заради цього аудиту не запускалися. Короткі локальні рендери перевіряють технічну коректність; повний ручний перегляд усіх готових роликів не входив до цього прогону.

Успішна перевірка підтверджує перелічені сценарії та виправлення. Вона не гарантує відсутності всіх можливих майбутніх помилок або безпомилковості художніх рішень зовнішньої моделі.

Для подальших змін корисно поступово розділяти великі модулі `app.js`, `store.py` і `languages.py` за процесами, зберігаючи тести й сумісність API. Заміна їх цілком заради меншої кількості рядків створила б окремий великий обсяг перевірки.

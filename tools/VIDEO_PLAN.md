# Швидкий план відео

`video_plan.py` робить PDF і JSON зі сценарію без звернень до мовної моделі. У PDF є кількість кадрів, тривалість, частки форматів і повний таймлайн. Скрипт не завантажує медіа та не монтує ролик.

## Запуск

```bash
python3 /Users/a11/Documents/YOUTUBE/VideoKey Studio/tools/video_plan.py --list
python3 /Users/a11/Documents/YOUTUBE/VideoKey Studio/tools/video_plan.py --channel 'Валентин Чичваркин' --script '/шлях/до/сценарію.txt'
```

Результат зберігається поруч зі сценарієм як `План видео.pdf` і `План видео.json`. За потреби можна задати `--output '/шлях/до/плану.pdf'`. Параметр `--duration 1800` масштабує приблизні часові межі до загальної тривалості озвучки в секундах. Він не створює точне послівне вирівнювання.

Важливі тези можна подати окремим невеликим JSON-файлом і додати `--hints '/шлях/до/акцентів.json'`. Ключ - номер речення від початку сценарію, значення - формат. Наприклад, `{"12":"text","27":"animation"}`. Підказки для вступних відеокліпів не замінюють відео. Центральний текст автоматично не розкидається за відсотком: він з'являється тільки на позначених важливих тезах. Автор сценарію може віддати цей короткий файл у тому самому завданні, без окремого виклику моделі.

## Налаштування каналів

Для звичайної роботи двічі клацніть `YOUTUBE/Налаштування відео.command`. У браузері відкриються налаштування з повзунками та смугою 100%. Якщо збільшити одну частку, інші автоматично зменшаться. Натисніть «Зберегти налаштування», щоб записати зміни для вибраного каналу. Вікно Термінала має бути відкритим, поки користуєтеся сторінкою.

У кожній папці каналу є `video-plan.json`, який ця сторінка змінює самостійно. На сторінці можна налаштувати:

- `short_sentence_words`: межу короткого речення, зараз 5 слів;
- `max_sentences_per_scene`: максимум речень на кадр, зараз 4;
- `words_per_minute`: орієнтир темпу для приблизного таймінгу;
- `opening_seconds`: довжину першої частини;
- `opening_clip_count`: цільову кількість різних відеокадрів у першій частині;
- `opening_clip_types`: типи вступних кліпів у порядку появи;
- `weights`: відносні частки типів для решти кадрів. Центральний текст задається лише через підказки.

Щоб додати канал, створіть його папку в `YOUTUBE` і скопіюйте до неї `video-plan.json` з близького за стилем каналу. Щоб прибрати канал зі списку, приберіть або перейменуйте лише його `video-plan.json`. Відсотки у PDF обчислюються з реальних тривалостей призначених кадрів. Ваги у файлі задають початковий розподіл, який можна змінити до затвердження.

Автоматичний план треба переглянути за змістом: скрипт визначає місце формату, але не може сам перевірити, чи конкретний стоковий кадр точно показує потрібну дію або деталь. Після озвучки фактичні часові межі звіряють з аудіо перед монтажем.

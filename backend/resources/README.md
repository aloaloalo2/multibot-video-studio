# Local narration audio

`voice-rooms/*.wav` contains wet-only stereo room impulses. The doctor's office uses a custom short furnished-room response generated by `tools/build_voice_office.py`: diffused close reflections, absorbed bass/sibilance and a quiet tail. Its mix keeps the direct voice dominant with at most 10% reflected gain. Other spaces use AVFoundation's matrix reverb from `tools/build_voice_rooms.swift`. Runtime preview and export use these exact files with normalization disabled; no Apple framework is required for playback on another computer.

`voice-roomtones/*.flac` contains short, filtered excerpts of CC0 field recordings. They are bundled for offline playback. The original pages, authors, public player URLs and license are recorded in `voice-roomtones/sources.json`. Runtime preparation crossfades the loop and levels it before mixing quietly under narration. No remote request is used for preview or export.

Processing version 3 maps the background volume to -60 through -30 dBFS RMS, with exact silence at 0%. The separate Play button uses the same gain as the narration mix and respects player volume/mute. It never boosts the selection audition. The checkbox controls inclusion in narration; audition can play with it off.

Processing version 4 introduces the doctor's-office response and its softer mix. Other spaces and background volume retain their existing behavior. A pending server upgrade uses its older response and gain formula until the server advertises version 4. Existing finished narration is not reprocessed automatically.

Tempo audition is rendered locally from the immutable dry take using the narration's FFmpeg `atempo` filter. The browser plays the lossless FLAC preview at 1x. Opening controls or changing speed must not call a voice service. A pending server upgrade retains its older background gain curve in the UI until the new processing version is available.

Sources: [IENBA](https://freesound.org/people/IENBA/sounds/761024/), [visionear](https://freesound.org/people/visionear/sounds/565535/), [mzui](https://freesound.org/people/mzui/sounds/135097/), [leonelmail](https://freesound.org/people/leonelmail/sounds/579571/).
